# Tests vs Readme Requirements — Task List

Generated by reviewing the test suite (PHPUnit `tests/Unit/*` + Behat `features/*`) against the
requirements and roadmap defined in `Readme.md` (Sections 2 "Key Features", 8 "Testing", and
10 "Roadmap").

## Summary

- PHPUnit Unit suite: 8 test files, 96 tests covering Audit, Dashboard, Documents, Expenses,
  Notifications, and Reports (ClientStatement, PeriodLock) services.
- Behat suite: 24 feature files covering Accounting, Auth, Clients, CreditNotes, Documents,
  Expenses, General/Navigation, Invoices (incl. Advanced/Estimates/Recurring), Payments

      `features/` exercising the 80% path. Add a unit test that queues/records the
      notification when a PO crosses 80% utilisation.
